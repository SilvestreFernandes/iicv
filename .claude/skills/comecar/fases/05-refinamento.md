# Fase 5 — Refinamento livre

**Objetivo:** aplicar os pedidos do dev até a autorização de entrega. **Modelo:** Sonnet.

- Aplique os pedidos; pergunte só quando houver duas interpretações com resultados diferentes.
- Em alterações de texto, atualize `projeto/COPY.md` antes do código.
- Se o pedido contrariar direção, regra de nicho ou escopo aprovado, explique em uma linha e espere autorização.
- Atualize ESTADO quando uma decisão aprovada mudar. Mantenha `DECISOES.md` e `REVISAO.md` em dia.
- A cada leva, confira as áreas alteradas em 375 e 1440 e rode `npm run verificar` antes de relatar conclusão.
- Versione conforme o modo salvo no ESTADO; push continua sujeito à aprovação das permissões.

## Fechar

Quando o dev disser “pode entregar”, registre o aceite no ESTADO, versione e siga para a fase 6.
